# 学习力报告原模板

此目录的入学、阶段模板由用户授权提供的原始 Word DOC 转为 DOCX 后制作。保留原稿封面、前言图形、章节框、表格列宽与颜色、页边框、页眉页脚、签名和回执结构；原姓名、学校、教师、成绩及分析样例均替换为字段，不将原学生记录随应用分发。

`manifest.json` 校验模板文件，并列出可填写字段。运行时只修改正文与页码刷新设置，其他包部件按原字节保留。知识分析、习惯、15次辅导计划及习惯方案使用原表格的数据行样式扩展；每节课标为“1节”，不推断钟点时长。明确选择在家长沟通参考处填入短文，签名始终留空。

入学原稿没有单独的前三次课观察、成绩目标或教师评语表，这些辅助资料仍在应用中保存并参与AI分析，不额外插入破坏原版式的Word章节。阶段变化归入原有整体评语格。导出为可编辑DOCX，可由Word或WPS打开；正文长度、字体环境与软件版本会影响自动分页，不固定报告总页数。

为忠于原稿，保留封面后的原有留白与显式分页；执行要求段落与标题保持相邻，避免只剩一行的续页。家长回执建议180字以内，最多240字，避免超过原固定回执框容量。原始DOC文件不修改。

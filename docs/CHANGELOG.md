# 1.10.1 — 作业优先选择学生个人文件夹

# 1.10.0 — AI 助手直接办事

- 全局助手默认进入“工作区 · 查找与办事”，按姓名、年级或学校匹配对象；具体学生助手保持该学生范围。
- 直接引用讲义、引用考试试卷及答案、关联考试（成绩留空）、登记课堂原文并后台准备反馈、添加学生观察、安排下次回访、标记作业完成；回访名单和搜索直接读取本地结果。
- 同名学生、同名资料和多卷别提供候选按钮，明确对象才办理；重复关联跳过，整组操作在一次保存中完成，失败不留半成品。
- 系统根据实际保存生成回执，保留最近50次记录，最近10次可在助手查看、重启后撤销；撤销保护后续手工修改、已填考试成绩、已用于授课或反馈的资料。
- 回访计划与历史沟通分开保存，直接进入回访待办；实际回访保存后接续新的下次联系日期。课堂与观察原文完整保留，模型不能补写学生事实。

# 1.9.0 — 一次课后记录、自动备课与反馈表达习惯

- 学生页新增“课后记一段”，默认今天，原文先保存并计次，再后台自动提取已讲范围、有原文依据的薄弱点、明确下次进度和作业；反馈独立作为草稿准备，切换页面继续，退出重启后续办，不重复计次。
- 学生打开即显示课前备课卡，带出上次范围、接课主题、未完成作业、课堂关注点与匹配讲义/试卷；已有事实与下一课建议分别标示。
- 自动反馈可预览、复制或载入编辑框，不覆盖已有手工草稿，不自动发送；保存后关联本次课，普通反馈流程继续可用。
- 从教师保存的AI反馈修改学习语气、篇幅、编号和常用表达偏好，下次生成自动应用；只持久化表达统计，不保留跨学生写作例句。个人信息处可恢复默认偏好。
- 后台结果有记录版本与时间保护，删除或手工修改后不被旧结果覆盖；原始记录始终保留，模型不可用时给出明确标记的本地草稿。
- 未审核的自动草稿和旧AI原文不作为学员事实传入报告或分析，避免把建议或已被纠正的内容当成观察。

- 无AI或请求失败也保留完整基础方案，区分已记录的事实与建议起点。高中人教A版、初中浙教新版；从“下次继续”接课，避免对数之后回退指数或集合。
- 原学校进度和人工补充折叠至“特殊情况修正”，旧内容保留，正常使用无需展开。报告和AI助手同步获得自动判断依据；历史报告继续遵循统计日期与已选资料范围。
- 修复资源首次加载尚未完成就提前自动请求的问题；缓存只关联本人资料、教材文件与模型设置，不因AI结果自身保存或其他学生改动循环生成。

# 1.4.1 — 复刻新建教案流程

# 1.4.0 — 复刻教案完善与学案生成

- 依据指定旧项目的流程与生成规则重建教案完善：填充3条目标、重难点、2–3段趣味导入和3条翻转总结，保留原Word模板、题目、公式、图片及页眉页脚。
- 按题型勾选并分配正文/随堂练习数量，自动重新编号；首次整理保留固定原始题目，后续可恢复未选用题。兼容旧项目已有基础题库源文件，仅将其作为只读原题来源，不恢复题库管理功能。
- 已有趣味导入与总结默认保留，空章节自动补齐；可校对AI草稿再保存，自动备份原教案，外部修改时拦截过期写入。
- 学案支持“仅复制”和“复制并处理”：整段移除答案解析，选择/填空留一行，解答题按答案长度及记住的系数/指数留白，优化题干分页，超长题目提示复核。
- 处理全部在应用内完成，不依赖Python；新增公式写入可编辑OMML。讲义反馈读取排除原始题目和历史备份，避免未选题目混入授课内容。

- 拦截明显评价对象错误和把建议充当优点的结果，自动修正一次；再次失败保留已有草稿。

# 1.2.1 按教材进度规划后续15节课

- 学科知识学习固定生成第1—15节课，每节独立给出教学内容、目标及重难点。15节表示15次授课，不按钟点时长合并成少数单元。
- 高中采用人教A版数学，初中采用浙教版新版数学；优先读取配置的本地教材目录，排除旧版和其他版本。扫描版和大体积PDF使用已核对的章节摘要，避免整本加载导致内存过高。
- 按人工补充、最近课堂记录、讲义及上期报告判断当前进度，显示判断依据；不能仅凭年级从教材开头重排。资料不足时给出标为待确认的建议起点。
- 新增可选的当前进度补充，以及「AI 重新规划15节课」；可只更新进度和知识方案，其他报告字段保留，预览确认后保存。
- 不足/超过15行、重复主题或缺少进度依据的AI方案会拦截。旧报告保持原样，新方案导出使用课次、内容、目标、重难点四列表格，跨页重复表头。

# 1.2.0 AI 生成完整学习力报告

# 桌面启动与常驻

- 支持构建并安装独立 macOS 应用，包含 Electron 运行时和生产依赖，日常无需终端或开发服务器。
- 关闭窗口或 ⌘W 改为隐藏，菜单栏可重新打开；默认全局 ⌘⇧J 唤起，配置中心可修改或禁用，冲突保留原有快捷键。
- 单实例锁避免重复启动；重复打开应用唤起现有窗口。显式退出前排空已排队的磁盘写入。
- 配置中心新增「启动与快捷键」，可选择登录自动启动，默认关闭。
- 中文应用名仍使用既有 `teaching-workspace` 用户数据目录，安装不迁移或覆盖学生资料。
- 新增打包、安装及真实安装包验证脚本；应用图标和菜单栏图标随包分发。

# 考试文件上传修正

- 试卷、答案分别选择，不再共用一个会替换选择结果的文件框；两类均支持多选和反复追加。
- 批量复制后一次追加关联，保留原有文件；也可单独保存试卷或答案，之后补充另一类。
- 已有文件分组新增补充按钮，沿用学科、学校范围和卷别。
- 失败保留已选文件；重试复用已成功复制的副本，不重复复制，不覆盖旧关联。
- 文件选择器新增多选模式，原单文件/目录选择行为保持不变；升级需重启桌面进程。

# 回访摘要整理

- 新增回访内容摘要输入，通过 DeepSeek 文本服务整理并填入九项结构化表单。
- 响应逐字段校验后才填入，不发送其他学生上下文，不补造摘要未提及的信息。
- 已有填写内容时先预览，可保留原草稿或确认替换；失败、取消不修改草稿，不自动保存记录。
- 九项字段及历史记录字段均提供独立复制，空字段禁用复制。日期和下次联系安排不被 AI 覆盖，停课学生保持只读。

# 考试管理更新

- 移除题库页面、菜单、配置和导入代码；错题管理保留，旧资料文件不自动删除。
- 联盟统考用一条考试记录关联多所学校，独考限定一校；含组织者、年级、完整日期和多学科满分。
- 试卷与答案按学科、适用学校、卷别分别配对；公共卷只保存一次，也可附学校专用版本。导入复制原文件，不覆盖同名文件。移除只解除关联。
- 学生详情新增考试成绩页，支持无成绩先关联、后补分、零分和缺考。部分出分不算作完整总分。
- 学校和年级保存历史快照，转校、升年级不改原记录；历史录入需要明确勾选并指定考试时学校。
- 已有成绩保护考试年级、参与学校、学科及满分；考试支持归档/恢复，有学生记录时禁止删除。
- 学校删除或改学段也会检查关联考试。

5. 微信群课堂反馈默认使用当天上课日期，可手动改；提取真实关联讲义正文，详细分点说明教学主题与内容，按教师记录扩写优点和不足各 2–3 条。结构校验通过后才生成可编辑草稿，不自动保存，也不补造未观察到的事实。

7. 配置改为有效字段白名单，启动时移除退役功能配置，旧路由回退到学生管理。升级后需重启桌面进程，使菜单与 preload 接口同时更新。

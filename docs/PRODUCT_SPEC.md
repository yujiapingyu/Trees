# 教培管理系统：功能说明与 AI 重建规格

> 本文基于当前项目代码整理，既是产品功能说明，也是可直接交给代码生成 AI 的重建任务书。文中的“必须”用于描述重建时应保留的核心行为；如果目标环境不是 uTools，应实现等价的桌面文件服务适配层，而不是把所有文件操作改成浏览器内存模拟。

## 1. 产品概述

### 1.1 产品定位

这是一个面向个人教师、小型教培团队的本地优先教学运营工作台。它以学生为中心，围绕“学生档案 → 讲义与作业 → 授课反馈 / 错题 → 家长回访 → 学情分析与下一步教学”形成闭环，并提供课本、练习、参考资料、视频、书籍和题库等资源入口。

产品不是单纯的 CRM，也不是单独的 AI 聊天工具。核心目标是把教师分散在本地文件夹中的学生资料、教案、练习、课堂记录和沟通记录组织起来，并在需要时通过 AI 做归纳、生成、识别和推荐。

### 1.2 目标用户与运行环境

- 主要用户：负责多个学生、课程资料和家长沟通的教师或教培从业者。
- 当前形态：uTools 桌面插件。
- 前端：React 单页应用，Vite 构建。
- 文件访问：通过 uTools preload 注入的 `window.services` 读取本地目录、读写文件、打开系统文件/文件夹、调用语音和文档处理能力。
- 配置与轻量业务数据：优先使用 `utools.dbStorage`；部分浏览器兼容路径使用 `localStorage`。课件、报告、录音、转写、题库和导出文档保存在用户指定的本地目录中。
- AI / 语音：DeepSeek 用于文本生成、摘要、分析和推荐；千问视觉模型用于题目图片识别和结构化抽取；本地 Whisper.cpp 用于录音转写。
- 当前实现以 macOS 文件路径与 `/Volumes` 外接盘路径为主要使用场景。重建时需将路径与平台能力做成配置，不得假设浏览器可直接访问本地任意文件。

### 1.3 核心价值

1. 快速定位学生、课程和资料。
2. 学生、讲义、反馈、作业、错题、学习报告和回访之间能互相衔接。
3. 不强制迁移用户现有文件：沿用本地目录结构，以文件夹作为主要资源来源。
4. 关键状态和偏好可持久化，关闭插件或切换页面后可恢复。
5. AI 输出须结合可用的学生事实和本地资源，不能凭空编造数据。

## 2. 全局界面与交互规范

### 2.1 主应用框架

- 全屏高度工作区，页面本身不整体滚动；各模块内部按内容独立滚动。
- 桌面端采用左侧窄导航 + 右侧主内容的两栏框架。左栏宽约 64px，深蓝灰渐变背景，图标在上、中文模块名在下，当前项使用蓝色强调色和左侧选中边框。
- 主内容区为浅灰底，业务页面通常使用白色卡片、边框、圆角、清晰标题与状态提示。
- 视口较窄时，导航改为顶部横向滚动菜单；页面内部应保持内容可访问，不得因固定宽度导致关键按钮不可操作。
- 页面整体以中文为主，采用蓝色作为主要操作色；错误、警告、完成、待处理等状态需要使用可区分的颜色和文本，不能只靠颜色表达。
- 页面应提供空状态、加载状态、错误状态和禁用状态；网络 AI 请求及文件转换应显示进度或明确提示。

### 2.2 当前主导航

主导航从上到下：

| 路由 | 名称 | 用途 |
|---|---|---|
| `students` | 学生管理 | 学生档案、课程、作业、反馈、错题、报告和学情分析 |
| `followups` | 回访管理 | 联系提醒、家长通话、录音转写和回访记录 |
| `studentNotes` | 学生记录 | 学生长期笔记与学生上下文 AI 助手 |
| `wrongQuestions` | 错题报告 | 跨学生错题统计、筛选和分析 |
| `teachingResources` | 教学资源 | 课本管理与分层规划的统一入口 |
| `teachingVideos` | 教学视频 | 视频目录、检索、播放、历史和笔记 |
| `lessonLibrary` | 讲义库 | 个人讲义资产、新建、整理和分配 |
| `visionDemo` | 视觉实验 | 多图像理解实验台 |
| `examAnalysis` | 试卷分析 | 合并试卷题目分类、考点变化和预测 |
| `questionBank` | 题库管理 | 试卷 OCR、题目抽取、标注和本地题库 |
| `settings` | 配置中心 | 路径、AI、语音、U 盘等配置 |

当前左侧导航实际显示以上 11 项。`books` 页面已在应用路由和插件命令中定义，但未出现在左侧导航；重建时可保留独立入口，若要加入导航，应视为明确的导航调整。

支持数字快捷键 `1` 至 `7`，依次切换学生管理、回访管理、教学资源、学生记录、错题报告、教学视频、讲义库。输入框、文本域、下拉框获得焦点时不响应；组合键和按住重复触发不响应。

切换到 uTools 插件入口时，应根据入口命令定位页面并恢复上次页面。`textbooks` / `planning` 命令进入“教学资源”并选择相应子标签；`assistant` 命令对应学生记录中的 AI 助手语境。页面路由和各模块视图状态均应持久化。

### 2.3 通用交互

- 文件/文件夹条目显示名称和适当图标；点击文件夹进入，点击文件用系统默认应用打开。
- 文件浏览器须提供当前路径、返回上一级、打开当前目录、搜索和空状态；不要越过当前资源根目录。
- 搜索优先支持名称及相对路径；学生搜索支持姓名、年级、电话、备注及拼音匹配。结果需有清晰的点击行为。
- 有常用资源的页面提供“收藏夹 / 最近访问”快捷访问面板，可收藏或取消收藏当前目录/文件、再次打开收藏项和最近项。
- 文件系统操作必须显示失败原因；危险操作（删除学生、删除/清理讲义文件等）应二次确认，必要时要求输入确认文本。
- 侧栏、筛选项、当前目录、选中学生或模块标签等重要浏览状态应按页面保留。

## 3. 核心业务对象与数据关系

### 3.1 学生

学生目录根目录下的一级文件夹代表一名学生，姓名必须唯一。学生资料包括姓名、年级、家长电话、备注、授课状态、课程目录、作业、反馈、错题、回访、学生记录和学习力报告。

学段/年级至少覆盖：小学一年级至六年级、初中一年级至三年级、高中一年级至三年级、中职。学生授课状态包括：

- 未授课
- 三次课内
- 稳定授课
- 已停课

授课状态可依据学生手动标记及已有关联课程信息展示；已停课学生在一些运营列表中默认排除或只读，但历史数据保留。

### 3.2 讲义与课程

- 学生目录中的一级子目录默认代表一份讲义/课程；`学习力报告`、`错题本`、`续费管理` 等特殊目录不能误识别为课程。
- 学生可引用个人讲义库中的讲义。引用与原始讲义文件分离：学生侧移除引用不得删除讲义库原件。
- 讲义可关联学生、参考资料、教学视频、反馈、作业和题目。重复关联应避免；被反馈引用的讲义引用不应被无提示地移除。
- 讲义库记录学段、年级、集合/来源、标签、排序、稳定标识、关联文件和资源链接。

### 3.3 资源

主要资源类型：讲义、参考资料、教学视频、课本、练习、书籍、分层规划表、模板、试卷与题目。大部分资源以本地路径为主键，并保存相对路径用于展示与搜索。

### 3.4 业务闭环

学生是核心聚合对象；讲义是教学载体；作业、课堂反馈、错题、报告和回访是教学过程记录；资源目录为备课与授课提供内容；AI 对上述信息做检索、摘要和建议。

## 4. 页面功能规格

### 4.1 学生管理

#### 页面布局

采用三栏工作区：

1. **学生列表栏**：新增学生、学生根目录快捷配置、学生搜索、年级筛选、授课状态筛选和学生列表。
2. **讲义列表栏**：当前学生的课程/讲义列表；可拖拽调整顺序、选择课程、从讲义库添加引用、打开学生文件夹、跳转至讲义库或移除引用。列表与详情之间有可拖动宽度分隔线。
3. **学生详情区**：学生信息、作业管理、当前讲义文件、教案摘要、关联资料、错题、学习力报告、课堂反馈和 AI 分析等内容。

#### 学生档案操作

- 新建：输入姓名，创建学生目录；校验姓名非空且不与已有学生重名。
- 搜索：姓名/年级/电话/备注，支持中文拼音；可按年级和状态筛选。默认不显示已停课学生，允许切换到全部状态或仅已停课。
- 编辑：修改姓名、年级、家长电话、备注；姓名改名时需同步关联的本地存储数据键。
- 停课/恢复：停课后保留历史资料，运营模块将其排除或显示为只读；可随时恢复授课。
- 删除：危险操作，展示确认步骤并清除/处理对应学生目录与数据前明确告知影响，不得误删其他学生或讲义库来源文件。
- 点击姓名可复制姓名；点击学生目录按钮可在系统文件管理器打开。

#### 课程、文件和资料

- 选择学生后扫描其一级课程目录；课程列表支持拖拽排序并保存顺序。
- 选择课程后展示课程中的文件（可递归展示相对路径），点击文件调用系统程序打开。
- 解析教案 DOC/DOCX 中教学目标、重点/难点等信息并在详情区展示；文件缺失或无法解析时显示空状态或提示，不伪造结果。
- 可从讲义库按学段、年级、集合和关键词筛选讲义，将讲义作为引用添加到当前学生；重复引用需提示。
- 展示关联参考资料及资源缺失状态；关联视频可从应用内部跳转到视频播放器。实际重建可以支持视频关联操作，但当前讲义库的相关入口由实现开关控制，默认未启用。
- 学生目录可包含学习力报告历史文件，点击打开。

#### 作业管理

- 在学生详情展开/收起作业区域。
- 从课本/练习/其他配置的作业来源中选择文件或文件夹，填写作业日期，添加到该学生的作业列表。
- 每条作业显示名称、来源、日期、相对路径、完成状态和参考答案状态。
- 支持切换完成/未完成、打开作业、移除作业、添加/更换/打开/移除参考答案。
- 支持重复添加校验；已删除或不可访问的来源应提示。

#### 课堂反馈与授课自动化

- 选择当前反馈对应的讲义；可直接输入本节课表现、掌握情况、薄弱点和课后建议，不强制填写问卷。
- 使用微信群反馈模板和学生/课程上下文，调用 DeepSeek 生成家长群反馈草稿。
- 草稿可编辑、复制、保存到学生反馈记录；历史反馈可展开、复制、编辑、删除。
- 在完成 AI 生成之前检查配置与必要输入；失败要显示错误，并可使用明确的本地模板回退（不得让用户误以为 AI 成功）。
- 支持授课录音自动化：开始/结束授课、保存录音、Whisper 转写、AI 草拟反馈；录音目录、whisper-cli、模型、语言在配置中心设置。

#### 错题、报告与学情分析

- 错题可按当前学生和课程管理；能从讲义题目中提取或人工录入题干、选项、答案、解析，并标记该学生错题。
- 学习力报告支持“入学报告”和“阶段报告”，可补充学科、学校、成绩、目标分数/排名、目标学校和特别要求；按学生相关数据生成并保存到学习报告目录，显示历史报告。
- 学情分析聚合学生档案、讲义、作业、反馈、回访、错题、报告等，生成学生总评、关键问题、趋势变化和下一步建议；支持结果缓存、更新时间提示与复制。
- 续费辅助可生成续费清单与数学课程规划，分别便于复制到 Excel / Word；必须遵守页面给定的结构与课时约束。

### 4.2 回访管理

#### 页面布局

- 左侧：统计卡片（需优先联系、逾期/未联系、本周应联系）、搜索框、状态筛选（需联系、逾期、已安排、全部）和学生列表。
- 右侧：选中学生摘要、回访记录、AI 电话沟通大纲/话术编辑区、录音转写自动化和历史回访列表。
- 列表展示学生年级、电话、最近回访、下次建议及状态徽标；电话可复制。

#### 提醒逻辑

- 建议默认按每次有效回访后 14 天安排下一次联系。
- 根据最近回访日期计算下次日期和状态：从未回访、逾期、临近（例如三天内）、已安排/未来待联系。
- “需联系”和“逾期”筛选优先展示需处理学生；“全部”包含停课学生历史，但停课学生只读，不计入当前联系任务。
- 搜索支持姓名、年级、电话、备注。

#### 回访记录与 AI

- 保存每次回访日期、沟通目的/内容、家长反馈、学习习惯、关键信息、解决方案、家长对方案反馈、备注及后续安排。
- 结合学生档案、近期课程、最近反馈及旧回访生成电话提纲和自然口语化家长话术；教师可编辑、复制、保存。
- 若 AI 不可用，提供清楚标记的本地模板作为备用，错误信息不得隐藏。
- 支持浏览器麦克风录制通话；结束录音后保存音频，调用本地 Whisper.cpp 转写，再由 DeepSeek 汇总为结构化回访纪要。展示通话时长、流程状态、转写文本、纪要及结果目录入口。
- 自动化失败时显示失败阶段与原因，允许重试转写；录音中可以取消本次录音。已停课学生禁用开始录音和新增沟通。

### 4.3 学生记录

- 左侧学生列表，支持姓名搜索、记录数量显示；默认排除停课学生。
- 右侧显示当前学生与记录总数。
- 支持新建、编辑、删除学生笔记；每条记录包含标题、日期、Markdown 内容；列表卡片可展开/收起。
- 编辑器提供“编辑 / 预览”切换，预览支持 GFM、数学公式（LaTeX）渲染。
- 学生数据保存在本地键值存储中。
- “AI 助手”弹窗使用当前学生为上下文，整合笔记、课堂反馈、回访、错题、讲义引用等统计与可用内容，支持多轮对话、取消请求、清空对话及动态快捷建议。
- API Key 未配置时显示去配置提示；AI 请求期间显示加载状态；模型输出用 Markdown + 数学公式渲染。不得把不同学生的上下文混用。

### 4.4 错题报告

- 左栏列出学生、错题总数、本周错题、本月错题统计；默认隐藏停课学生，支持姓名/年级/电话/备注搜索。
- 选中学生后读取其课程，并显示可选课程及错题报告详情。
- 支持按时间范围筛选（本周、本月、近 N 次课、全部），查看错题记录、按课程关联。
- 可对当前错题集合做 AI 分析，输出错因归纳和教学建议；空数据时提示先标记错题。
- 页面可折叠学生侧栏；筛选和当前学生应持久化。
- 学生管理页内也嵌入针对当前学生/课程的错题管理和报告面板，修改需与独立错题页读取同一份记录。

### 4.5 教学资源（课本管理 + 分层规划）

教学资源是一个带子标签的复合页面。子标签为“课本管理”和“分层规划”，从 uTools 的 textbooks/planning 命令进入时自动选中对应标签，离开后记住上次选择。

#### 课本管理

- 初中/高中切换卡片。
- 展示对应配置目录的一级文件与文件夹；点击打开系统路径。
- 提供“打开当前目录”及快捷访问收藏/最近列表。
- 目录由用户自由组织，不要求特定文件命名。

#### 分层规划

- 初中/高中目录切换，支持多级文件夹浏览、返回上级、打开当前目录、递归搜索与全量刷新。
- 支持 Excel 规划表读取和表格预览；按可识别的年级、程度等字段筛选，支持当前表格内容搜索（包含拼音匹配）。
- 预览需保留表格结构、表头和内容；无法解析时提供系统打开原文件的入口。
- 规划目录结构应允许按年级或专题组织，推荐表头包含主题、教学目标、重难点、程度等信息。

### 4.6 教学视频

- 左侧浏览器 + 右侧视频播放器。
- 浏览器顶部支持初中/高中学段切换；当目录可识别多个年级时提供年级筛选。
- 展示当前位置、面包屑、当前文件夹子目录、当前目录视频数量；可返回上级、打开当前目录、搜索视频标题/章节/路径。
- 搜索全索引视频并显示相对目录路径；点击搜索结果定位到浏览器位置并选择视频。
- 右侧播放本地视频，支持播放/暂停、进度拖动、快进/快退、播放速度（0.75x、1x、1.25x、1.5x、2x）、播放完成处理。
- 保存最多约 80 条观看历史及播放进度，支持续播。
- 视频笔记可编辑、保存为富文本/结构化内容并与视频路径绑定；观看历史与笔记面板互斥显示。
- 支持专注模式、退出专注快捷方式（Esc）、折叠左侧栏、打开视频所在文件夹。
- 可调用 AI 依据视频索引生成推荐；推荐结果显示意图、视频名称、路径和理由，点击定位到视频。
- 视频目录及索引需考虑文件变动后的刷新；路径不存在时显示错误或从失效列表中清理。

### 4.7 讲义库

#### 浏览与筛选

- 学段标签：初中、高中、中职。
- 初中/高中讲义按年级/复习阶段和集合组织；中职可不细分年级。
- 搜索标题、年级、路径，也可回车将关键词作为标签筛选；支持多标签筛选、标签颜色、最近使用标签、清空筛选。
- 列表展示讲义名称、面包屑/来源等信息；支持按创建时间或用户拖拽的自定义顺序排列并持久化。
- 选择讲义后右侧显示讲义详情、文件列表、标签、关联学生、参考资料链接和操作消息。

#### 创建与资源管理

- 从配置的模板目录选 DOC/DOCX 模板，在目标学段和年级下创建新的讲义文件夹，并复制模板文件。
- 可重命名讲义；删除和清理文件前明确列出影响文件并确认。
- 支持管理标签、查看/打开文件夹、复制教案路径。
- 支持关联参考资料（搜索名称或路径、添加/移除）、学生分配与取消分配；若引用关系已被学生反馈使用，应阻止无提示移除。
- 讲义资源链接应引用路径，路径失效时标记为缺失而不是静默删除。

#### 讲义处理工具

- **教案完善**：基于原教案正文和提示词调用 DeepSeek，生成更完整教案；可设置题型与题量、调整题目数量；重做覆盖前生成备份；输出须经过结构校验，失败显示错误。
- **转学案**：对教案复制生成学案，或调用 DOCX 处理服务将教案转换为含学生作答空间的学案。支持覆盖检查、布局检查和空白量参数；参数范围由界面校验（空白量系数 0.1–1.5，增长指数 0.5–1）。
- **打包讲义**：根据学段、教材版本、年份、年级及讲义名称，把讲义文件整理/导出为约定结构；参数不完整时禁止执行。
- **清理文件**：列出待删文件，取消或确认删除；对历史教案目录等需保留内容做保护。
- **排序**：可拖拽改变讲义顺序，关闭后应恢复。

### 4.8 视觉实验

- 独立的多模态图片理解实验台，三段式界面：图片输入、分析任务、模型输出。
- 支持拖放/选择本地 JPEG、PNG、GIF、WebP 图片；单图不超过 32 MiB，最多 8 张；可添加公开 HTTP(S) 图片 URL；图片可预览和移除。
- 预设任务包括自由提问、作业分析、文字提取、图表解读；选中后仍可改写 Prompt。
- 图片细节模式包括自动、低细节省 Token、原图保留细节。
- 调用 DeepSeek 视觉接口，结果以 Markdown/LaTeX 渲染，可复制。
- API 未配置时提供去配置入口；校验图片类型、大小和网络请求错误。

### 4.9 试卷考点整理与预测

- 从系统文件选择 DOCX 合并试卷；页面显示文件、文件大小、标题和处理进度。
- 对合并文档解析来源与题目；未识别到题目时给出文件级错误。
- 调用 DeepSeek 对题目分类，分层整理为大类/小类（主题/知识点），比较跨试卷考点变化，并预测后续重点。
- 进度分为读取、分类、预测、导出；每阶段向用户说明当前文件/任务。
- 分析结果可导出为 Word；单份源文件时优先复制原 Word 后重新组织题目，必要时转换生成新 DOCX。
- 可打开输出文件；分析失败和导出失败均需显示原因。执行前要求已配置 DeepSeek API Key。

### 4.10 数学题库

- 左侧本地题库专题列表，显示学段、年级、版本、题数和导入模式；主区显示导入流程或所选题库。
- 导入模式：原试题 + 解析版，或仅原试题。支持选择 DOC/DOCX/PDF；双文件模式需要匹配同一资料的试题版与解析版。
- 将文档按页转为图像，调用千问视觉模型抽取题号、题干、选项、答案、解析、题目/图形区域；跨页碎片合并，再将答案解析配对。
- 调用 DeepSeek 生成类别、知识点标签和难度（基础/中等/较难）；对不确定内容保留可编辑状态，不伪造答案。
- 题库数据保存为本地 JSON，题目图片和页面图片存于题库目录；题库索引保存在 uTools dbStorage。
- 题目列表支持数学公式渲染，修改类别、难度、标签等后显式点击保存；只有含解析的题库显示答案/解析。
- 提供“打开题库目录”；缺失数据文件时从列表移除并提示；缺少千问或 DeepSeek 配置时提供去配置入口。

### 4.11 书籍

- 本地目录浏览，显示文件/文件夹，点击文件夹进入、点击文件系统打开。
- 搜索名称与相对路径，结果点击后进入文件夹或打开文件。
- 支持当前路径、返回上一级、打开当前目录、收藏和最近访问。
- 目录结构自由，隐藏系统文件不显示；搜索结果数量应有限制并排序。

### 4.12 配置中心

#### 配置导航与保存

- 左侧分类：学生与讲义、语音转写、参考资料、教材与练习、分层规划与设备、目录说明。
- 右侧按分类显示配置项、说明、路径状态、选择按钮和恢复默认按钮。
- 显示“已保存 / 有未保存修改”；修改后点“保存配置”提交，取消/重置草稿恢复已保存值。
- 目录/文件字段可手动输入或通过 uTools 文件选择器选择；显示路径存在、可读、文件可用或错误。
- API Key 默认隐藏，可切换显示；模型名和服务地址可编辑。
- “分层规划与设备”页面可扫描 macOS `/Volumes` 下已挂载目录，用于 U 盘路径选择/刷新。
- “目录说明”呈现真实目录组织示例和注意事项，帮助用户自行建目录。

#### 配置项

| 分组 | 配置 |
|---|---|
| 学生与讲义 | 学生分类目录、个人讲义库目录、讲义模板目录、题库目录、微信群反馈模板、DeepSeek API Key / 模型、千问 API Key / 模型 / Host |
| 语音转写 | 课堂录音目录、回访录音目录、Whisper 可执行文件、Whisper 模型文件、Whisper 语言 |
| 参考资料 | 初中/高中/中职参考资料根目录 |
| 教材与练习 | 初中/高中课本根目录、初中/高中练习根目录、教学视频目录、书籍目录 |
| 分层规划与设备 | 初中/高中规划目录、U 盘挂载目录 |

API Key 不应写入源码、默认值或生成的文档；保存到本地配置存储。

## 6. 数据持久化与索引

### 6.1 存储原则

- 业务文档和媒体文件优先保存在本地用户目录；配置、笔记、关联关系、轻量状态保存在 uTools dbStorage。
- 视图状态使用独立键空间，写入可短暂防抖；插件关闭或页面卸载时必须刷新未完成写入。
- 对需要浏览器演示的开发环境可以有 `localStorage` 后备，但生产桌面文件能力仍应经 preload 服务实现。
- 所有业务引用以稳定 ID 或完整路径作为识别依据；路径缺失时在界面标记并允许修复。
- 不得把异步 AI 结果当成事务性成功保存；应在成功返回后更新 UI 和数据文件。

### 6.2 当前可见的存储键范式

重建时可兼容现有命名，也可建立统一数据层映射，但语义须保留：

- `sm_path_config_v1`：路径和模型配置。
- `sm_view_state_<module>`：模块视图状态。
- `student_<学生名>`：学生档案/人工状态。
- `student_lesson_refs_<学生名>`：学生引用的讲义。
- `feedback_<学生名>`：课堂反馈。
- `followup_<学生名>`：回访记录。
- `student_notes_<学生名>`：学生笔记。
- `student_wrong_questions_<学生名>`：错题记录。
- `student_analysis_<学生名>`、`student_renewal_<学生名>`：学生分析和续费生成缓存。
- `stage_report_<学生名>`、`admission_report_<学生名>`：学习力报告相关记录/状态。
- `teaching_video_history_v1`、`teaching_video_notes_v1`：视频历史与笔记。
- `lesson_tag_recent_usage`、`lesson_study_plan_blank_settings`：讲义标签偏好和学案设置。
- `question_bank_index`（具体键常量在题库模块定义）：本地题库目录索引。
- 各快捷访问模块保存收藏和最近访问。

学生改名时应迁移所有以姓名为后缀的关联数据。对于批量迁移或删除，需保证不会覆盖同名/已有目标数据。

## 7. AI、文档与语音处理边界

### 7.1 AI 服务职责

- **DeepSeek 文本模型**：课堂反馈生成、学生分析、续费/课程规划、学生记录问答、回访摘要/话术、参考资料与视频推荐、教案完善、试卷分类与预测、题目标签。
- **千问视觉模型**：试卷页图像 OCR、多模态题目抽取与答案解析识别。
- **DeepSeek Vision**：视觉实验台中的图像问答、作业/图表理解与文字识别。
- **Whisper.cpp 本地服务**：课堂录音和回访录音转写；转写结果再交给 AI 做摘要或反馈草稿。

### 7.2 AI 质量与失败处理

- AI 只可引用已提供的学生档案、教学记录和本地资源；未知内容应明确标为未知或待确认。
- 结构化结果应校验必需字段和输出格式；解析失败时显示原始错误/可重试入口，不要静默吞错。
- 显示所用模型、任务状态或配置缺失提示；长任务显示阶段与进度。
- 生成文本可编辑，用户复制/保存前始终保留人工校对机会。
- 对模板回退明确标识“本地模板 / 非 AI 生成”。
- AI 提示词中明确隐私边界：只将当前任务所需信息发送到用户配置的服务；不要意外把所有学生数据拼入任意请求。

### 7.3 文件和预加载服务

桌面环境通过 preload 服务提供如下能力类别：读取目录/文本/DOCX/Excel、检查路径、创建目录、打开文件、复制/删除/重命名文件、写入 JSON/图片、读取文件元数据、转换 Word/PDF 页面图像、语音转写、调用 AI、管理录音自动化任务。

前端组件不应直接使用 Node 文件系统 API；应通过可测试的服务接口操作，并将服务错误映射成用户可理解的错误消息。

## 8. 推荐技术架构

重建版应维持简单、可替换的分层：

1. **呈现层**：React 页面、通用表单/对话框/列表/状态提示、各模块 CSS。
2. **应用层**：学生选择、课程分配、搜索、提醒规则、AI 任务编排和导出流程。
3. **领域层**：Student、Lesson、Homework、Feedback、WrongQuestion、FollowUp、Resource、Report 等数据结构与校验。
4. **基础设施层**：StorageAdapter、FileSystemService、UtoolsAdapter、AIProvider、SpeechTranscriptionService、DocumentService。

实现约束：

- 将 uTools API 和文件读写封装在适配器中，使页面能够在测试环境使用 mock 服务。
- 路径配置变化后，依赖路径的页面及时刷新，不沿用已失效目录。
- 统一复用搜索、拼音匹配、文件排序、快捷访问、日期处理、路径相对化和 AI 请求状态等共享逻辑。
- 单个页面不要把所有业务永久堆在一个组件内；拆分组件时围绕明确职责拆分，避免无意义抽象。
- 删除/重命名/批量保存要检查关联关系，并提供可恢复或明确确认策略。
- 重要状态提供键盘可访问性和焦点管理；弹窗应可关闭、阻止背景误操作。

## 9. 非目标与当前入口说明

- 本应用不是在线多租户 SaaS，不需要账号体系、云端数据库、权限角色或支付流程。
- 不是在线网盘；核心资源由教师本地目录持有。
- 不应为了重建而自动抓取或上传整个本地目录。
- 仓库中还存在参考资料、练习、AIAssistant、Planning、Textbooks 等独立组件。其中课本和规划通过“教学资源”嵌入；`books` 路由可由插件命令访问但当前左侧导航没有书籍项；左侧导航没有单独挂载“参考资料”和“练习”页面，独立 AI 助手命令也映射到“学生记录”语境。重建时如需额外开放这些独立组件，应作为明确的导航范围变更，不要误认为当前导航已有入口。
- uTools 专属插件进入/退出、文件选择器、preload 文件服务不可由普通浏览器直接打开完整替代；无 uTools 时应展示环境提示或开发 mock 模式，而不是假装文件功能正常。

## 10. 可直接复制给代码生成 AI 的总提示词

```text
你是一名资深桌面应用工程师。请从空项目开始，重建一个中文、本地优先、面向教师的“教培管理系统”桌面应用。目标是按以下产品规格实现完整可运行的应用，而不只是生成静态界面。

【产品定位】
这是以学生为中心的教学运营工作台：管理学生档案、讲义与作业、课堂反馈、错题、学习力报告、回访和教学资源，并用 AI 辅助内容生成、资料检索、学情分析、题目识别和视频推荐。默认数据保存在本地；文件通过桌面 preload/service adapter 访问。不要引入 SaaS 登录、云数据库或支付模块。

【技术与运行架构】
1. 使用 React + Vite 构建单页应用；前端不得直接调用 Node 文件系统。
2. 建立 StorageAdapter、FileSystemService、Desktop/UtoolsAdapter、AIProvider、TranscriptionService、DocumentService。桌面版通过 preload 提供 API；开发/测试时可注入 mock。无桌面 API 时应显示环境提示，不能伪造文件操作成功。
3. 配置和轻量业务数据使用桌面 key-value storage；文本、文档、音频、图片、题库 JSON 和导出结果保存到用户设置的本地目录。
4. DeepSeek 用于文本生成/分析/摘要/推荐；千问视觉模型用于试卷 OCR 和结构化题目识别；Whisper.cpp 本地 CLI 用于录音转写。API Key 只由用户配置，不写入源码。
5. 页面状态、路径、异步错误和加载进度要明确；文件缺失、目录不可读、AI失败、文档解析失败都必须反馈。

【全局界面】
桌面端使用全屏工作区、左侧约 64px 深蓝灰窄导航、右侧浅灰内容区；导航图标在上、中文标签在下，选中项蓝色高亮。主内容使用白色卡片、清晰标题、轻边框和卡片间距。内容内部独立滚动。视口小于约 600px 时导航改成可横向滚动的顶部导航。所有页面有空、加载、错误、成功状态，破坏性操作需确认。

左侧主导航依次为：
学生管理、回访管理、学生记录、错题报告、教学资源、教学视频、讲义库、视觉实验、试卷分析、题库管理、配置中心。另保留书籍页面及其插件命令入口，但不默认增加左侧导航项。
1-7 数字键分别打开：学生管理、回访管理、教学资源、学生记录、错题报告、教学视频、讲义库；输入框聚焦时禁用快捷键。记住当前路由和每个模块的筛选/目录/选中状态。

【本地目录】
所有根路径可在配置中心调整。学生目录根下每个一级文件夹代表学生；学生目录下一级课程目录代表讲义，但“学习力报告”“错题本”“续费管理”等是特殊目录。个人讲义库按学段→年级或复习集合→讲义目录组织；模板目录放 DOC/DOCX；参考资料按初中/高中/中职配置，内部层级自由；课本、练习、书籍、视频、规划表使用自由目录结构；规划表主要是 Excel；录音分别存课堂与回访目录；题库有独立根目录；U盘目录由用户配置。

【页面一：学生管理】
做三栏工作区：
- 左栏学生列表：新增、学生目录配置、搜索姓名/年级/电话/备注（中文拼音也能匹配）、年级过滤、授课状态过滤。状态包括未授课、三次课内、稳定授课、已停课；默认排除已停课。
- 中栏课程列表：来自当前学生目录的一级课程目录，支持拖拽排序、选择课程、打开学生文件夹、从讲义库添加/移除引用、跳转讲义库；引用不能重复，不能因移除学生引用而删除讲义库原件。
- 右栏学生详情：编辑姓名、年级、家长电话、备注；标记停课/恢复；删除时二次确认。显示课程文件、教案摘要、关联参考资料/视频、学习力报告历史、作业、课堂反馈、错题和 AI 学情分析。
- 作业：从配置资源中选文件或文件夹、设作业日期，支持完成状态、打开、移除、添加/替换/打开/移除参考答案。
- 课堂反馈：选择课程，输入课堂表现/掌握/薄弱点/建议；用模板及学生上下文生成可编辑微信群反馈，复制和保存历史；支持本地录音、Whisper转写、AI草拟。AI失败不能显示成成功。
- 错题：能从讲义题目抽取或手工填写题干、选项、答案、解析，标记为当前学生错题。
- 学习力报告：入学/阶段两种，收集学科、学校、成绩、目标分数/排名、目标学校和补充要求，生成并保存历史报告。
- 学情分析：聚合学生档案、讲义、作业、反馈、回访、错题和报告，输出总评、关键问题、趋势、下一步建议；可生成续费清单及课程规划。

【页面二：回访管理】
左侧统计需优先联系/逾期未联系/本周应联系；搜索学生；筛选需联系、逾期、已安排、全部。右侧显示学生年级、电话（可复制）、最近回访、下次建议和历史。每次回访后建议 14 天联系，显示从未回访、逾期、临近和已安排状态。记录沟通目的、内容、家长反馈、习惯、关键信息、解决方案、家长对方案反馈及后续计划。根据学生档案、最近课程与反馈生成电话沟通大纲和话术，可编辑、复制、保存。支持麦克风录音、计时、结束后保存、Whisper转写、DeepSeek结构化摘要；显示阶段、错误、重试和结果目录。停课学生只读且不能开始录音。

【页面三：学生记录】
左栏学生搜索和记录计数，默认排除停课。右侧支持笔记新建/编辑/删除/展开，字段为标题、日期、Markdown 内容，提供编辑/预览，预览支持 GFM 和 LaTeX。AI助手弹窗按当前学生隔离上下文，结合笔记、反馈、回访、错题和讲义，支持多轮问答、快捷建议、清空、取消请求和 Markdown/公式显示。

【页面四：错题报告】
学生列表及错题总数、本周、本月统计；默认排除停课；按学生/年级/电话/备注搜索。按本周、本月、近N次课、全部筛选错题；支持 AI 错因分析及教学建议。学生管理内嵌的错题面板和独立页必须读写同一数据。

【页面五：教学资源】
复合页含“课本管理”和“分层规划”两个子标签，并记住上次子标签。
- 课本：初中/高中切换，列目录下文件与文件夹，点击打开，提供打开目录和收藏/最近访问。
- 分层规划：初中/高中目录切换，目录浏览/返回/打开/刷新/递归搜索；读取 Excel 表格预览，按年级/程度筛选，表格内容支持搜索和拼音匹配，解析失败时可系统打开原 Excel。

【页面六：教学视频】
左侧初中/高中浏览器，支持年级筛选、路径面包屑、目录和视频列表、搜索标题/章节/路径、定位搜索结果；右侧本地播放器支持播放/暂停、进度拖动、快进快退、0.75/1/1.25/1.5/2倍速。保存最多80条历史和续播进度；支持视频笔记、专注模式、折叠侧栏、打开所在目录。提供 AI 视频推荐并展示理由，点击后定位播放。

【页面七：讲义库】
初中/高中/中职标签，按年级、集合、标题、路径、标签筛选；支持多标签、最近标签、排序和拖拽顺序。选择讲义后显示文件、标签、学生、参考资料。可从 DOC/DOCX 模板新建讲义，重命名、打开、删除、清理文件；危险操作确认。支持讲义分配学生、关联参考资料。提供教案 AI 完善（题型/题量可调、覆盖前备份、校验结果）、教案转学案（复制或 DOCX 转换、覆盖提示、空白量设置和版式检查）、讲义打包（学段/教材版本/年份/年级）及讲义顺序管理。资源路径失效需标记。

【页面八：视觉实验】
选择/拖放最多8张 JPEG/PNG/GIF/WebP，每张最多32MiB；支持公开HTTP(S)图片URL。显示预览并可移除。任务模板有自由提问、作业分析、文字提取、图表解读；Prompt可改。细节选项自动/低/原图。调用DeepSeek视觉，输出Markdown/LaTeX，可复制；显示API配置状态、加载和错误。

【页面九：试卷考点整理与预测】
导入合并DOCX试卷，展示文件大小、标题、移除和处理进度。解析题目后用DeepSeek分类为大类/知识点，比较跨卷考点变化并预测重点。阶段为读取、分类、预测、导出；结果可导出为Word并打开。识别不到题目、缺少API、导出失败均需明确提示。

【页面十：数学题库】
左侧专题索引，主区导入或编辑题库。两种模式：原试题+解析版，或仅原试题；支持DOC/DOCX/PDF。双文件必须配对试题版和解析版。按页转图片，用千问视觉抽取题干/选项/答案/解析/题目图形，合并跨页碎片并配对答案；用DeepSeek添加类别、知识点标签、基础/中等/较难难度。写questions.json和图片资源到本地题库目录，索引放本地key-value。题目可编辑、数学公式渲染、显式保存。题目不确定时允许人工修订，不得捏造。

【页面十一：书籍】
目录浏览、面包屑/当前路径、返回上级、打开当前目录、搜索名称及相对路径、点击文件系统打开、收藏/最近访问。隐藏系统文件。

【页面十二：配置中心】
左侧分类：学生与讲义、语音转写、参考资料、教材与练习、分层规划与设备、目录说明。字段覆盖学生/讲义/模板/题库/反馈模板目录、DeepSeek与千问凭据和模型、课堂/回访录音目录、whisper-cli/模型/语言、初高中中职资料目录、初高中课本练习规划目录、视频书籍根目录和U盘挂载目录。路径可手填或用桌面选择器选择，实时显示存在/可读状态；API Key可显隐；保存/重置草稿；可扫描macOS /Volumes。提供目录结构指南。凭据不得硬编码。

【快捷访问与搜索】
课本、练习、书籍、参考资料等资源页面可复用快捷访问面板：收藏当前路径、收藏列表、最近访问列表、重新打开和取消收藏。搜索文件名及相对路径，中文支持拼音匹配；结果限制数量并可定位。

【数据模型建议】
Student(name, grade, phone, notes, status, directoryPath)
Lesson(id/stableId, name, path, stage, grade, collection, tags, order, files)
Homework(id, studentId, path, dueDate, completed, answerPath)
Feedback(id, studentId, lessonId, date, content, transcript, audioPath)
WrongQuestion(id, studentId, lessonId, stem, options, answer, explanation, createdAt)
FollowUp(id, studentId, date, nextDate, purpose, content, parentFeedback, solution, notes, audioPath, transcriptPath)
StudentNote(id, studentId, title, date, markdown)
Resource(path, name, relativePath, type, metadata)
Report(studentId, type, generatedAt, content, sourceSnapshot)
所有存储必须按学生隔离；用户更名时迁移相关键；本地文件失效时显示状态而非崩溃。
```

# 知序 · 教培管理

中文、本地优先的教学运营桌面工作台。React + Vite 构建界面，Electron preload 提供本地文件、文档与 DeepSeek 文本服务。产品不内置演示学生或假文件。

## 启动

推荐 Node.js 24 LTS 或 26+：

```bash
npm install
npm run desktop
```

开发桌面版使用 `npm run desktop:dev`；仅浏览器预览使用 `npm run dev`。浏览器会明确显示本地文件服务未连接。

首次到「配置中心」连接学生、讲义、教材等本地根目录。已有学生文件夹会扫描为档案。macOS 也可双击项目中的 `启动知序.command`。

## 当前模块

左侧共 9 个入口：学生管理、回访管理、学生记录、错题报告、教学资源、教学视频、讲义库、题库管理、配置中心。书籍页保留桌面「页面」菜单入口。快捷键 1–7 顺序保持不变，输入时禁用。

- 学生：新建、改名、档案编辑、停课/恢复、拼音搜索、年级/状态筛选；稳定 ID 隔离数据，真实目录操作受配置边界限制。
- 学校：在配置中心「学校管理」中按初中、高中自行添加、改名。学生档案选择关联学校，列表、详情、搜索及 AI 上下文显示学校。关联中的学校不能直接删除或切换学段；先修改关联学生。
- 讲义引用：从学生页关联或从讲义库分配，新的引用均排在该学生课程列表最前；已有顺序和课程保留，可继续拖拽调整；重复引用与反馈关系受保护。
- 作业：来源、日期、完成状态、参考答案与移除；来源文件保留。
- 微信群课堂反馈：上课日期默认当天（可改），读取所选讲义的教案/正文，提取主题与详细分点内容；结合教师记录，优点和不足各 2–3 条。缺乏事实的扩写采用建议或观察方向，不补造发言、分数、正确率或作业完成情况。AI 输出先校验，再生成可编辑、可复制、可保存的纯文本反馈；本地模板明确标为非 AI。
- 回访：14 天联系建议、逾期/临近/安排状态、停课只读、结构化记录、AI 沟通提纲与话术。
- 学生记录：Markdown / LaTeX 笔记与按学生隔离上下文的多轮 AI 助手。
- 错题与报告：共用错题数据、时间/课程筛选、AI 错因分析；入学/阶段 Word 报告、学情分析缓存、带课时约束的续费清单与课程规划。
- 教学资源：本地目录、递归搜索、收藏与最近访问；XLSX / CSV 多表预览及年级/程度筛选。
- 视频：本地播放、倍速、快进快退、续播、最多 80 条观看历史、Markdown 笔记、专注模式、AI 推荐。
- 讲义库：分层筛选、标签与顺序、模板创建、改名、学生分配、参考资料、AI 完善、覆盖备份、DOCX 转学案与分页预览、文件清理和目录打包。
- 题库：手工录入和编辑；DOC / DOCX / 有文字层 PDF 的正文提取，DeepSeek 提取题目、配对答案和标注类别/难度；显式保存 JSON，并复制原始试卷供后续核对。扫描件需先转换为文字版，图形需人工核对。已有题库与图片资源仍可读取。

视觉实验、试卷分析、千问接入，以及本地课堂/回访录音转写均已移除。运行时配置仅允许当前有效字段，旧功能凭据和工具路径在启动时从有效配置中清理；旧学生业务记录及资源文件保留。

## 外部配置

| 功能 | 需要 |
| --- | --- |
| 文本生成、课堂反馈、学生分析、题库文本提取 | DeepSeek API Key、文本模型及兼容服务地址 |
| DOC 正文、Word 转 PDF、学案分页预览 | LibreOffice；macOS 默认尝试 `/Applications/LibreOffice.app/Contents/MacOS/soffice`，可在「文档转换」中指定其他路径 |

API Key 只由用户填写，保存在本机配置文件中。请求在桌面主进程发送，内容限定为当前任务所需资料。

## 数据与备份

- 配置、学校、学生业务与视图状态：Electron `app.getPath('userData')/workspace.json`，文件权限 0600。
- 配置键：`sm_path_config_v1`；业务聚合：`sm_workspace_v1`；界面状态：`sm_view_state_<module>`。
- 学校存于业务聚合的 `schools` 数组：`id / name / stage`；学生用 `schoolId` 关联。旧档案没有学校时保持未关联。
- 报告、题库 JSON、原始试卷、教学资源：用户配置的本地目录。
- 浏览器使用 localStorage 后备，与桌面数据不自动同步。
- 备份需同时覆盖 `workspace.json` 与教学资料目录。JSON 内含已保存的凭据，请妥善保管。
- 删除真实资源进入系统废纸篓；资源覆盖前备份并明确确认。移除学生讲义引用不会删除讲义库原件。
- 更换学生根目录后，旧档案保留并停止扫描越界路径，可切换到当前目录的同名学生，不自动合并两个学生 ID。

建议目录：

```text
学生根目录/学生姓名/
  方程复习/教案.docx
  学习力报告/
  错题本/
  续费管理/

个人讲义库/高中/高二/概率分布/教案.docx
```

## 验证

```bash
npm test
npm run build
npm run test:e2e
npm audit
```

端到端测试使用系统 Chrome 和真实 Electron，数据写入独立临时目录并在结束时清理。AI 由本地测试 HTTP 服务模拟，仅用于验证请求上下文、结构校验和持久化，不宣称验证真实模型质量。学案分页预览的测试使用真实 LibreOffice 和 PDF.js。

## 实现边界

- 当前为 Electron 桌面版，尚未制作 uTools 插件包或签名安装程序，也不自动迁移原系统的旧版姓名存储键。
- XLS 旧格式需另存为 XLSX。没有文字层的扫描试卷应先做外部 OCR；导入不会猜测图片题目或补造答案。
- DOCX 转学案保留原 XML 结构、按编号插入空白并移除独立答案段落；复杂答案图片、公式与分页需人工校对。AI 完善保存为标准 Word 排版，覆盖前备份。
- 视频依赖 Chromium 支持的编码；笔记为 Markdown，不是所见即所得富文本。
- 文件系统操作与 JSON 索引更新不构成数据库事务；写入失败会报错，可从备份/废纸篓恢复并刷新。
- 目前主要在 macOS 验证，其他平台仍需检查系统工具路径和媒体编码。

# 知序 · 教培管理

中文、本地优先的教学运营桌面工作台。React + Vite 构建界面，Electron preload 提供本地文件、文档与 DeepSeek 文本服务。产品不内置演示学生或假文件。

## 启动

日常使用直接打开 `~/Applications/知序.app`，无需 Node.js、终端或 Vite 后台服务。可拖入 Dock，也可通过 Spotlight 搜索「知序」。

- 默认全局快捷键 **⌘⇧J**，窗口在前台时再按一次隐藏；隐藏、最小化或切到其他应用后按下会调出知序，页面和未保存草稿保留。
- 关闭窗口或 ⌘W 隐藏后仍驻留菜单栏；再次打开应用只唤起现有窗口。
- 「配置中心 → 启动与快捷键」可修改快捷键、禁用快捷键或开启登录自动启动（默认关闭）。快捷键冲突会提示，保留原有可用快捷键。
- 彻底退出用菜单「退出知序」或 ⌘Q；退出后再次双击应用启动。
- 更新安装保留原有用户数据目录；首次运行 1.3.0 自动将旧 JSON 迁移到 SQLite，原文件和额外备份保留。菜单栏和后台驻留不依赖终端；显式退出前等待已排队的磁盘写入完成。

首次从源码打包安装需要 Node.js 24 LTS 或 26+：

```bash
npm install
npm run install:mac
```

生成的应用在 `release/知序-darwin-arm64/知序.app`（Intel 架构对应 x64），并复制到 `~/Applications/知序.app`。安装前请退出旧版；旧应用会备份，学生数据与资源不动。仅构建使用 `npm run package:mac`。本机构建采用 ad-hoc 签名。

开发桌面版使用 `npm run desktop:dev`，或 `npm run desktop` 运行构建后的界面；仅浏览器预览使用 `npm run dev`。浏览器会明确显示本地文件服务未连接。

首次到「配置中心」连接学生、讲义、教材等本地根目录。已有学生文件夹会扫描为档案。`启动知序.command` 优先打开已安装应用，首次运行时会构建安装。

## 更新应用

已安装的 `.app` 是独立版本，修改项目代码或更新 GitHub 仓库不会自动改变它。目前没有自动检查或下载新版的功能。

1. 我们完成本地代码修改后，先保存应用里的草稿，再用 ⌘Q 或菜单「退出知序」彻底退出；只关闭窗口会驻留后台。
2. 双击项目里的 `更新知序.command`。它会从当前本地代码构建新版，先完成复制再替换应用，保留旧应用备份，随后自动打开。需要本机已有 Node.js 和项目依赖，缺少依赖时自动安装。
3. 到「配置中心 → 启动与快捷键」查看当前版本。学生档案、回访、成绩、配置和教学资源不放在应用包内，替换应用不会清空这些数据。

也可将已打包的新版 `知序.app` 替换到 `~/Applications/知序.app`。旧应用仍运行时不要替换。`启动知序.command` 只负责启动已有应用，不负责更新；`更新知序.command` 使用当前本地代码，不会自动拉取 GitHub。

## 当前模块

左侧共 9 个入口：学生管理、回访管理、学生记录、错题报告、教学资源、教学视频、讲义库、考试管理、配置中心。书籍页保留桌面「页面」菜单入口。快捷键 1–7 顺序保持不变，输入时禁用。

- 学生：新建、改名、档案编辑、停课/恢复、拼音搜索、年级/状态筛选；稳定 ID 隔离数据，真实目录操作受配置边界限制。
- 学校：在配置中心「学校管理」中按初中、高中自行添加、改名。学生档案选择关联学校，列表、详情、搜索及 AI 上下文显示学校。关联中的学校不能直接删除或切换学段；先修改关联学生。
- 讲义引用：从学生页关联或从讲义库分配，新的引用均排在该学生课程列表最前；已有顺序和课程保留，可继续拖拽调整；重复引用与反馈关系受保护。
- 考试课程引用：学生管理的「课程讲义 → 引用考试」可按考试、学科、学校范围及卷别引用试卷；新引用置顶并支持排序。试卷和答案沿用考试管理文件，同组新增文件会同步显示，不重复上传，也不自动创建考试成绩。可引用归档考试用于复习讲评，未参加考试或年级不同的学生也可使用。课程反馈从所选试卷正文提取讲评方向，不混入其他学校/卷别或假设整卷讲完。
- 作业：来源、日期、完成状态、参考答案与移除；来源文件保留。
- 微信群课堂反馈：上课日期默认当天（可改），读取所选讲义的教案/正文，提取主题与详细分点内容；结合教师记录，优点和不足各 2–3 条。缺乏事实的扩写采用建议或观察方向，不补造发言、分数、正确率或作业完成情况。AI 输出先校验，再生成可编辑、可复制、可保存的纯文本反馈；本地模板明确标为非 AI。
- 回访：学生详情右上角「回访」可按当前学生直接进入，自动清除旧搜索和筛选；14 天联系建议、逾期/临近/安排状态、停课只读、AI 沟通提纲与话术。以教师第一人称准备提纲和自然话术，优先结合本次摘要。输入回访摘要可生成沟通目的、沟通内容、家长反馈、学习习惯、关键信息、解决方案、家长对方案反馈、后续安排、备注九项并填入表单；基于摘要展开沟通目的、问题影响、执行建议及后续关注点，新增做法明确写为建议，未提及的事实留空，已有草稿先预览确认替换，生成不自动保存。每个字段与历史字段均可独立复制。
- 学生记录：Markdown / LaTeX 笔记与按学生隔离上下文的多轮 AI 助手。
- 错题与分析：共用错题数据、时间/课程筛选、AI 错因分析、学情分析缓存、带课时约束的续费清单与课程规划。
- 学习力报告：一键AI生成完整入学/阶段报告，无需先填表；自动汇总已有资料，提出目标、动力评估、课堂观察、习惯评级与课时计划，生成完整评语与家长沟通建议，确认后自动保存草稿，所有项目可修改。重新生成默认保留人工修改；未知事实标注待确认，身份与实际课次不由AI编造。学科知识学习按当前进度生成后续15次授课，高中采用人教A版、初中采用浙教新版，可单独重新规划15节课。支持入学三次课确认、阶段2—3个月待办、旧报告对比、Word导出。详见 [学习力报告流程](docs/LEARNING_REPORTS.md)。
- 教学资源：本地目录、递归搜索、收藏与最近访问；XLSX / CSV 多表预览及年级/程度筛选。
- 视频：本地播放、倍速、快进快退、续播、最多 80 条观看历史、Markdown 笔记、专注模式、AI 推荐。
- 讲义库：分层筛选、标签与顺序、模板创建、改名、学生分配、参考资料、AI 完善、覆盖备份、DOCX 转学案与分页预览、文件清理和目录打包。
- 新建教案沿用当前学段，选择标准或已有扩展年级与模板；中职不分年级。完整复制为 `讲义标题（教案）.原扩展名`，创建后自动选中，同名不覆盖，模板原件不修改。
- 考试：一条联盟考试可关联多所学校，学校独考限定一校；支持考试名称、组织者、年级、完整日期、多学科及满分。试卷和答案按学科、学校范围、卷别配对，文件复制至考试资料目录，原文件保留。 上传弹窗提供试卷、答案两个独立区域，均支持多选和反复追加；可一并保存，也可只上传一类再补充。已有分组可直接补充文件并沿用卷别。
- 成绩：学生可先关联考试、稍后补分；未出分、缺考、零分分别保存。不完整成绩只显示已录入分数，不误算为总分。保留当时学校与年级快照，支持明确的历史考试模式。已有成绩时保护考试年级、学校、学科与满分，并提供归档/恢复。

视觉实验、试卷分析、千问接入，以及本地课堂/回访录音转写均已移除。运行时配置仅允许当前有效字段，旧功能凭据和工具路径在启动时从有效配置中清理；旧学生业务记录及资源文件保留。

## 1.6.0 讲义标准打包、考试分类与原稿报告

- 讲义打包沿用原项目：根据学段预选人教A版/浙教版、当前年份及来源年级，在当前讲义目录生成ZIP；ZIP内一个标准名称目录，仅放标准命名的教案与学案，保留原扩展名和文件字节。高中年份不加“年”，初中年级规范为七/八/九年级，已有前缀不重复。不再要求U盘目录。
- 同名ZIP必须勾选备份覆盖；并发与外部变动受保护。缺少学案时按原项目规则复制教案作为学案，界面明确说明不会自动去除答案；历史、备份及原始题目文件不作为当前来源。
- 考试新增初中/高中分类、年级快捷按钮及数量，各年级分别成组，组内按考试日期倒序；搜索、学校及归档筛选继续生效并保留选择状态。
- 学习力报告Word改为直接填充用户原稿提炼的入学/阶段模板，保留封面、前言、图形、页框、表格、签名与回执；只替换对应栏目。模板不含样例个人信息，原DOC不修改。知识计划仍是15次课，原5列表格课时处标“1节”；内容较长自然续页，不固定总页数。
- 入学原稿未设的观察、目标和教师评语等辅助信息仍保留在应用与AI依据中，不额外插入Word章节；阶段变化写入原整体评语格。家长回执沟通参考建议180字以内、最多240字，签名保留空白。

## 1.5.0 教学记录与数据保护

- 学生详情新增「授课记录」：逐次登记日期、状态、主题、实际分钟数、关联讲义/考试、实际讲授范围、课堂观察及下次进度；完成课次自动累计，缺课/取消不计次。学习报告中可校准历史次数，后续编辑、删除仍正确计数。
- 课堂反馈可关联本次授课，带入日期、范围和原始观察；AI仅围绕实际范围整理内容，不将整份讲义视作已经讲完。报告、分析和后续15次授课规划共用实际授课资料及教材规则，实际时长与课次分开。
- 回访表单/摘要、反馈、学生记录编辑、学习报告编辑、授课表单和学生助手对话逐次编辑立即保存到本机设置库，按数据集和学生隔离；切换页面及重启后恢复。明确取消/清空会丢弃对应草稿。草稿不作为正式业务记录，不随数据库备份迁移。
- 报告资料读取包含学生记录的Markdown正文，兼容旧content；助手近期记录按实际日期排序，不受补录顺序影响。
- 学情分析、续费清单和课程规划保存生成时的资料快照；档案、授课、成绩等变化时显示具体更新提醒，重新生成保留最近5个历史版本。课程规划与续费清单统一为后续15次授课，不再固定每次2课时。
- 每个数据集每天首次打开及跨日保存前自动备份，保留最近30个备份日；「配置中心 → 数据与备份」可预览并恢复，切换前保护备份也可选择恢复。
- 完整备份是独立文件夹，包含SQLite及选中的资料目录，逐文件校验；恢复时创建新目录、自动重定位资料路径，先保护当前数据，不覆盖原资料。本机密钥、快捷键和草稿不导出。备份位置须在所选资料目录之外；目录内符号链接须先处理，不跟随复制外部文件。
- 学生删除改为应用回收站：真实目录暂存在学生根目录的隐藏回收目录，关联记录一起保存，学生页可恢复。目录移动记录持久化日志，异常中断后重新启动会完成恢复；同名学生/目录不覆盖。此前旧版本已经永久移除的业务记录不会凭空恢复。
- 主按钮悬停和键盘焦点使用深蓝底白字，普通/危险按钮各自保持可读文字颜色。

## 数据与备份

- 业务数据：SQLite，默认 `~/Library/Application Support/teaching-workspace/workspace.sqlite`。在「配置中心 → 数据与备份」更改保存文件夹，也可以选择云同步文件夹。
- 按学生、学校、课程引用、考试、成绩、回访、反馈、报告等分别建表，嵌套内容按记录保存，映射按键保存；SQLite 事务按变更的记录更新。使用 Electron 内置 `node:sqlite`，无需安装数据库服务或原生插件。
- 本机工作库位于 `userData/workspaces/<UUID>.sqlite`；本机配置、凭据、桌面偏好及页面状态在 `userData/preferences.sqlite`，均为 0600 权限。配置和凭据不进入可同步的业务数据库。
- 云同步位置保存完整数据库快照，实际读写在本机 SQLite 完成，再通过 SQLite 备份 API 导出完整文件并原子替换；使用 DELETE 日志和 FULL 同步，不向云盘暴露活动 WAL。退出等待排队写入完成。
- 位置切换前预览数据量、自动备份本机数据库；迁移保留原位置文件，不覆盖已有数据库。打开已有数据库是切换数据集，不合并记录。
- 所选文件失联、无权限或被外部修改时，本机改动仍可靠保存，并显示持续提示，可重试或另存。重启时若本机无未发布改动，可加载云盘的新版本；双方均改动时不自动覆盖。
- 多设备请轮流使用：退出当前设备并等待云盘同步完成，再打开另一台。保持数据库下载到本机；本功能不是多人实时协作或自动合并工具。云盘自身的上传进度由云盘软件负责。
- 配置键：`sm_path_config_v1`；业务聚合：`sm_workspace_v1`；界面状态：`sm_view_state_<module>`。
- 桌面偏好：`sm_desktop_preferences_v1`（全局快捷键与登录启动偏好）。登录启动的实际状态以系统设置为准。
- 课程关系仍存于 `refs`：普通讲义使用 `lessonId`，考试引用使用 `type: "exam"` 和 `examId / subjectId / schoolId / version`；考试课程标识为 `exam:<引用ID>`，兼容原有反馈与错题中的 `lessonId` 课程字段。
- 学校存于业务聚合的 `schools` 数组：`id / name / stage`；学生用 `schoolId` 关联。旧档案没有学校时保持未关联。
- 报告、考试试卷与答案、教学资源：用户配置的本地目录。考试资料根目录由 `examsRoot` 配置。
- 浏览器使用 localStorage 后备，与桌面数据不自动同步。
- 使用「导出数据库备份」保存完整 `.sqlite`，通过「打开已有数据库」恢复。教学资料目录另行备份；本机设置库需单独备份。旧 JSON 仅作为迁移前备份，不会继续更新，其中含原有凭据，请妥善保管。
- 学生删除进入应用内回收站；其他真实资源删除进入系统废纸篓；资源覆盖前备份并明确确认。移除学生讲义引用不会删除讲义库原件。
- 更换学生根目录后，旧档案保留并停止扫描越界路径，可切换到当前目录的同名学生，不自动合并两个学生 ID。

建议目录：

```text
学生根目录/学生姓名/
  方程复习/教案.docx
  学习力报告/
  错题本/
  续费管理/

个人讲义库/高中/高二/概率分布/教案.docx
```

## 实现边界

- 当前为 Electron 桌面版，尚未制作 uTools 插件包或签名安装程序，也不自动迁移原系统的旧版姓名存储键。
- XLS 旧格式需另存为 XLSX。考试模块保存与打开原始文件，不识别题目或推测成绩。原题库功能、配置及导入代码已移除，旧文件不自动删除。
- 教案完善按原表格与章节填充目标、重难点、导入和总结，保留原版式与未更新内容；可按题型分配正文和随堂练习，固定原题文件仅用于重新分配，覆盖前自动备份。新增公式写入可编辑 Word 公式。转学案支持原样复制或整段删除答案解析，选择/填空留一行，解答题按答案行数计算空间；未识别或超长题目明确提示，并可分页预览。仅支持 DOCX，DOC 需先另存为 DOCX。
- 视频依赖 Chromium 支持的编码；笔记为 Markdown，不是所见即所得富文本。
- 学生回收站通过持久化操作日志协调目录移动和SQLite更新；其他文件系统操作与数据库更新仍不是同一事务，写入失败会报错，可从备份/废纸篓恢复并刷新。

### 全局搜索与统一助手（1.7.0）

顶栏“全局搜索”（⌘K）可以搜索业务记录正文，支持姓名拼音和多关键词；搜索结果直接定位对应记录。点击“刷新资源文件名”可加入配置资源目录中的文件名，不读取文件正文。

顶栏“AI 助手”（⌘⇧A）先选择资料范围，发送时使用已配置的AI服务。学生对话彼此独立，通用教学不带学生记录，概览仅带统计及待回访名单，讲义与考试范围仅带目录信息。参考资料可跳转查看，回答不会自动修改业务记录。

在“配置中心 → 浙江教材与进度”维护同校同年级同学期的共用安排，在“学生 → 教材进度”单独覆盖。学校进度是同步目标，实际授课和下次进度是辅导起点；报告、课程规划和助手共同使用。未设置时仍自动规划并说明建议依据。初中排除旧版教材；九下新版未配置时明确提示，不以旧版代替。

### 自动教学规划（1.8.0）

进入“浙江教材与进度”或学生的“教材进度”即可查看自动生成的15节课。系统直接使用档案年级、学期、授课记录、课堂反馈、教师记录和关联资料，自动匹配教材与后续内容；已有AI配置时自动细化并保存，无须先维护学校进度表。新记录会使旧方案失效，下次查看自动更新；未变化的方案重启后复用。没有AI或服务暂不可用也会生成完整基础方案。学校特殊安排仍可在折叠的“特殊情况修正”中补充，默认无需操作。

### 教师个人信息（1.8.1）

点击左下角教师头像，可编辑并保存个人信息。保存后的显示称呼用于侧栏，姓名用于新学习报告默认署名；学生单独指定的教师优先，已有报告和班主任信息不受影响。信息随当前SQLite数据文件与完整备份保存，关闭编辑框前未保存的修改会作为本机草稿保留。

### 课后一次记录与自动备课（1.9.0）

学生页点击“课后记一段”，只写一段实际课堂记录即可；日期默认为今天，讲义和时长可不填。原文先保存，系统随后在后台整理反馈草稿、课堂关注点、下次接课点和课后练习方向；切换页面继续处理，重启可续办。草稿在“课堂反馈”中预览、复制或编辑后保存。

学生的备课卡自动汇总最近已完成课程、接课主题、未标记完成的作业、已记录的薄弱点和相关资料。反馈保存时会从你的改稿学习表达特征，后续生成自动参考语气与篇幅；不把其他学生的事实作为写作样例。可在左下角个人信息中恢复默认表达习惯。

### AI 助手直接办事（1.10.0）

点击顶部“AI 助手”（或 ⌘⇧A），默认进入工作区。可以直接输入：

- 给王品越引用对数讲义。
- 给高一学生引用A9联盟11月测试试卷。
- 给王品越关联A9联盟11月测试考试。（成绩留空）
- 给王品越登记今天的课堂记录：今天讲了对数运算，计算要检查真数条件，下次继续对数函数。
- 给王品越记一条观察：计算时需要检查符号。
- 下周五回访李政博。
- 把王品越的对数作业标记完成。
- 整理本周需要回访的学生。

操作按当前已登记对象和资料执行；同名或多卷别可点选。保存后显示真实回执和“撤销这次操作”；“最近办理记录”保留重启后的入口，最多保存50次回执、展示最近10次。后续已有独立修改或使用的记录不会被强行撤销。记录正文来自你的完整原文，课堂反馈随后在后台生成草稿；安排回访不会伪造历史沟通。通用、概览和资源范围继续只读。当前不执行删除、配置修改或外部消息发送。

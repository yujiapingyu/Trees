# 知序 · 教培管理

中文、本地优先的教学运营桌面工作台。React + Vite 构建界面，Electron preload 提供真实文件、文档、AI 与语音服务。项目初始为空，未导入任何真实学生资料，产品中没有演示学生或假文件。

## 启动

推荐 Node.js 24 LTS 或 26+。首次运行：

```bash
npm install
npm run desktop
```

开发桌面版：`npm run desktop:dev`。仅浏览器预览：`npm run dev`，访问终端中的本地地址。浏览器会明确显示文件服务未连接，文件操作不会伪装成功。

首次进入「配置中心」，连接本地学生、讲义、教材等根目录。保存配置后自动扫描学生目录。所有目录均可自行选择；不会自动读取未配置的个人文件夹。

- 学生目录扫描、新增、改名、档案编辑、停课/恢复、搜索和筛选。稳定 ID 关联学生业务；改名迁移资料路径，避免同名覆盖。扫描与更名串行，处理 macOS 路径别名。
- 三栏学生工作区、课程扫描、拖拽排序、宽度调整、讲义库引用去重与反馈关系保护。
- 作业日期、来源、完成状态、参考答案、移除；课堂反馈生成/编辑/复制/历史；手工错题和讲义抽取；入学/阶段报告 Word 保存；学情分析缓存；带课时校验的续费 TSV 和课程规划。
- 回访 14 天提醒、逾期/临近/安排状态、停课只读、结构化沟通记录、话术、录音转写草稿。
- 学生 Markdown / LaTeX 记录；按学生隔离上下文的多轮 AI 助手，支持取消与清空。
- 共用错题数据、时间/课程筛选、统计、错因 AI 分析。

## 外部配置

| 功能 | 需要 |
| --- | --- |
| 文本 AI | DeepSeek Key、模型和兼容服务地址 |
| 图片实验 | 支持图片的视觉模型与兼容服务地址；沿用 DeepSeek Key。默认文本模型不支持图片 |
| 题库 OCR | 千问 Key、兼容地址和视觉模型，以及 DeepSeek 分类配置 |
| DOC 正文、Word 转页图 | LibreOffice；macOS 默认尝试 `/Applications/LibreOffice.app/Contents/MacOS/soffice`，其他位置在配置中指定 |
| 录音转写 | 麦克风权限、FFmpeg、whisper-cli、Whisper 模型文件和录音根目录 |

密钥由用户在配置中心填写，仅存于本机配置文件。AI 请求在桌面主进程发送，前端不直接处理跨域凭据请求。不同任务只发送当次需要的学生或资源信息。

## 数据和文件

- 配置/轻量业务：Electron `app.getPath('userData')/workspace.json`，文件权限 0600。配置键为 `sm_path_config_v1`；业务聚合为 `sm_workspace_v1`；视图为 `sm_view_state_<module>`。
- 浏览器后备：localStorage，和桌面数据不自动同步。
- 资源文档、报告、题库 JSON、题目图片、音频/转写：用户配置的资源目录。
- 删除真实资源进入系统废纸篓；业务记录删除会明确确认。原始讲义的学生引用不会删除讲义库文件。
- 路径失效保留关联并提示；重新连接对应目录可恢复。更换学生根目录后，旧目录档案会明确标记并停止扫描，支持切换到当前目录中的同名学生；不会自动合并两个学生 ID 或删除历史资料。

建议学生目录结构：

```text
学生根目录/学生姓名/
  方程复习/教案.docx
  学习力报告/
  错题本/
  续费管理/
```

讲义目录建议 `个人讲义库/初中/初一/讲义名称/教案.docx`，高中同理，中职可直接放讲义目录。`学习力报告`、`错题本`、`续费管理`等不会识别成课程。

## 验证

```bash
npm test           # 业务约束与真实文件服务
npm run build     # 生产构建
npm run test:e2e  # 浏览器与 Electron 端到端流程
npm audit
```

端到端测试使用系统 Chrome；桌面测试创建独立临时数据目录，完成后清理，不触碰使用者的教学目录。题库端到端测试使用真实 LibreOffice 和 PDF.js 转图，AI 响应来自本地测试 HTTP 服务；视频测试使用浏览器 MediaRecorder 生成短视频。可通过 `npx playwright test tests/e2e/app.spec.js` 仅运行不依赖这些外部工具的浏览器测试。

## 明确边界

- 当前交付是 Electron 桌面替代实现，并非可直接安装到 uTools 的插件包。`window.services` 隔离协议可替换为 uTools preload；原入口命令已在路由适配处保留，桌面「页面」菜单提供对应入口和书籍页。尚未制作签名的 macOS/Windows 安装包。
- 原系统旧版按学生姓名分散存储的数据不会自动导入；本实现使用稳定 ID 和统一数据层，避免后续改名串号。已有学生文件夹会扫描为新档案；旧的轻量记录需独立迁移。
- AI、真实麦克风及 Whisper 模型准确度需要使用者配置后实机验收。测试 HTTP 服务仅在测试中注入，生产不会生成假响应。
- XLS 旧格式需在系统软件中另存为 XLSX。旧 DOC 依赖 LibreOffice。复杂扫描件、跨页/重复题号和图形裁切需要人工校对；未确定答案不会补造。
- DOCX 转学案按编号题目插入作答空间、移除独立答案段落，保留原始 XML 结构；支持通过 LibreOffice + PDF.js 分页预览检查，复杂表格、嵌入公式、答案图片和分页仍需人工检查。AI 完善保存为标准 Word 文档，不保证保留原排版，覆盖前备份并须明确确认。
- 视频播放依赖 Chromium 可用编码，不支持的编码需在系统播放器打开或先转码。视频笔记为 Markdown / 结构化字符串，不是所见即所得富文本编辑器。
- 本地文件删除和数据索引更新跨越文件系统与 JSON 存储，不构成数据库事务；若磁盘写入失败，界面会报错，可从系统废纸篓/备份恢复文件并刷新索引。
- 目前实测 macOS。Windows/Linux 的应用壳可运行，但系统废纸篓、转换工具路径和本地视频编码仍需平台验收。

完整原始需求见 [PRODUCT_SPEC.md](docs/PRODUCT_SPEC.md)。

## 代码组织

`src/pages` 为页面，`src/components` 为共用界面，`src/shared/domain.js` 为业务规则，`src/shared/store.jsx` 为应用状态与写入队列，`desktop/core.cjs` 为可测试基础设施，`desktop/main.cjs` 与 `preload.cjs` 为桌面适配。

本机验收发现当前 Homebrew FFmpeg 缺少 `libx265.215.dylib`，应在配置中心指定能正常运行的 FFmpeg 后再验收语音转写；项目未改动系统工具安装。
